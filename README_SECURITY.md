# 🛡️ Root Security & Environment Guide

הקבצים הבאים הם ה"לב" המאובטח של המערכת:

1. **.env** - נמצא בתיקיית השורש. מכיל את המפתח הסודי. (מוגן, לא עולה לגיט)
2. **.gitignore** - נמצא בתיקיית השורש. אומר לגיט ממה להתעלם.
3. **config.py** - המרכזייה שמקשרת בין הקוד להגדרות.

## פקודות שימושיות:
- לראות את כל הקבצים (כולל נסתרים): `ls -a`
- לערוך את המפתח: `nano .env`
